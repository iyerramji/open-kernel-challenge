# Reference catalog — task-specific inspection priority

This order ranks relevance to the selected dense-projection workspace, not universal speed or competition placement. Ten requested public references plus official SGLang and its pinned custom dependency are cloned. GPU MODE infrastructure is included because the official judge credits it; it is not mislabeled as optimized winning kernel code. No local H200 benchmarks were run. All claimed results below are upstream evidence, not verified measurements. Full pins are in references.lock.json.
